# 📝 สรุปแพลตฟอร์ม Alli Coworker & LLM App Market
> **TL;DR (Top-Level Summary):**
> แพลตฟอร์ม **Next-Generation No-Code** สำหรับองค์กรที่ช่วยสร้าง **AI Agent** และ **Web App** ได้ผ่านการแชทเพียง 10 นาที โดยไม่ต้องมีเทคนิคัล (Vibe Coding) รองรับการทำงานร่วมกับ SaaS และความปลอดภัยระดับ Enterprise

## 📌 Key Takeaways
* **No-Code & Vibe Coding:** พัฒนา AI Agent และแอปพลิเคชันได้โดย **ไม่ต้องมีความรู้ด้านการเขียนโปรแกรม** เพียงแค่สั่งงานผ่านแชท AI จะทำการ Coding ให้โดยอัตโนมัติ
* **Enterprise Security & Hybrid Deployment:** รองรับทั้งแบบ **SaaS, Private Cloud และ On-premise** มีระบบจัดการสิทธิ์ (SSO/IP Limit) และข้อมูลที่ใช้จะไม่ถูกนำไปเทรน AI ต่อ (Opt-out)
* **Cost-Efficiency:** รูปแบบราคา **ไม่จำกัดจำนวนผู้ใช้งาน (Unlimited Users)** เริ่มต้นที่ **300,000 เยน/เดือน** เหมาะสำหรับการขยายตัวทั้งองค์กร

## 📖 เนื้อหาสรุปเชิงลึก (Detailed Summary)

### 1. ผลิตภัณฑ์หลักและจุดเด่น
* **Alli Coworker:** เน้นการ "สร้าง" เครื่องมืออัตโนมัติ เช่น **Dashboard**, **ระบบจอง**, หรือ **Agent วิเคราะห์ข้อมูล** สามารถเชื่อมต่อกับ `Teams` หรือ `Slack` ได้
* **Alli LLM App Market:** แหล่งรวมแอปฯ และ Agent สำเร็จรูปกว่า **100 รายการ** ที่เลือกมาปรับใช้ได้ทันที (Ready-to-use)
* **เทคโนโลยี RAG ระดับสูง:** รองรับการดึงข้อมูลจากเอกสารที่มี **ตารางหรือรูปภาพ (Table/Figure Recognition)** ได้อย่างแม่นยำ และสามารถเลือกใช้ LLM รุ่นล่าสุดได้หลากหลาย เช่น `GPT-4`, `Gemini`, หรือ `Claude`

### 2. การประยุกต์ใช้งานตามแผนก (Use Cases)
| แผนก | ตัวอย่างการใช้งาน |
| :--- | :--- |
| **ฝ่ายขาย** | สร้างข้อเสนอการขาย, Roll-playing, วิเคราะห์คู่แข่ง |
| **ฝ่ายบุคคล/ธุรการ** | สอบถามระเบียบการบริษัท, จองห้องประชุม, สรุปประวัติผู้สมัคร |
| **ฝ่ายกฎหมาย** | ตรวจสอบความเสี่ยงสัญญา (NDA Review), ตรวจสอบข้อบังคับ |
| **ฝ่ายบัญชี** | ตรวจสอบค่าใช้จ่าย, จัดประเภทข้อมูลใบแจ้งหนี้ |

### 3. โครงสร้างราคาและบริการสนับสนุน
* **ค่าใช้จ่ายเบื้องต้น (Initial Fee):** 300,000 เยน (ครอบคลุมการตั้งค่าและ Support)
* **ค่าบริการรายเดือน (Monthly Fee):** เริ่มต้น **300,000 เยน** (ราคาอาจแปรผันตามฟีเจอร์และ Model ที่เลือก)
* **Support:** มีทีม **Customer Success** คอยให้คำปรึกษาแบบ On-boarding และมีบริการ Consulting สำหรับการทำ Workshop หรือสร้าง Agent เฉพาะทาง
