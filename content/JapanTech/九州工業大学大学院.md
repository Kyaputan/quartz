# 📝 สรุปงานวิจัย Kyutech: การคำนวณแบบเรซัวร์ (Reservoir Computing) เพื่ออนาคตของ Edge AI
> **TL;DR (Top-Level Summary):**
> **Kyutech** พัฒนาชิป AI และระบบ FPGA ที่ใช้สถาปัตยกรรม **Reservoir Computing (RC)** ซึ่งโดดเด่นในการประมวลผลข้อมูลอนุกรมเวลา (Time-series) ได้เร็วในระดับไมโครวินาที โดยใช้พลังงานต่ำกว่า 1 วัตต์ ช่วยแก้ปัญหาคอขวดด้านการสื่อสารข้อมูลระหว่าง Edge และ Cloud

## 📌 Key Takeaways
* **Extreme Efficiency:** ชิปมีขนาดเพียง 3mm x 4mm กินไฟต่ำกว่า 1W และประมวลผลได้เร็วระดับสิบไมโครวินาที
* **Online Learning on Edge:** ระบบ FPGA แบบวงแหวน (Ring topology) ที่สามารถเรียนรู้และปรับตัวได้แบบเรียลไทม์ (Online Learning) โดยไม่ต้องพึ่งพาคลาวด์
* **Integrated Optimization:** ชิปตัวใหม่ **CBM-Dual** สามารถทำทั้งการพยากรณ์ (RC) และการหาค่าเหมาะสมที่สุด (Annealing) ได้พร้อมกันในชิปเดียว

## 📖 รายละเอียดทางเทคนิคและนวัตกรรม (Technical Innovations)

### ⚡ 1. ชิปเรซัวร์สำหรับหุ่นยนต์บริการ (Home Service Robot App)
การนำชิป AI เฉพาะทางมาใช้เพื่อลดภาระการประมวลผลหลัก:
* **Gesture Recognition:** ใช้ประมวลผลการจดจำท่าทางมือ (Hand Gesture) เพื่อปลุกหุ่นยนต์ให้ตื่นขึ้นมาทำงาน
* **Energy Saving:** ลดการใช้พลังงานมหาศาลเมื่อเทียบกับการใช้ CPU/GPU ทั่วไป โดยที่ยังคงความแม่นยำและความเร็วเท่าเดิม
* **Hybrid Workflow:** เมื่อชิป RC ตรวจพบท่าทางสั่งงานแล้ว จึงค่อยส่งต่อไปให้ LLM ขนาดใหญ่จัดการเรื่องการโต้ตอบภาษาธรรมชาติและการจัดลำดับงาน



### 🏗️ 2. ระบบ FPGA แบบวงแหวนพร้อมการเรียนรู้ออนไลน์ (Ring-type RC on FPGA)
นวัตกรรมการออกแบบวงจรเพื่อเพิ่มประสิทธิภาพบนบอร์ดขนาดเล็ก:
* **Virtual Nodes:** ใช้เทคนิคการแบ่งเวลา (Time-division multiplexing) เพื่อจำลองโหนดจำนวนมากในวงแหวน ช่วยให้ระบบมีขนาดเล็กและราคาถูก
* **Online Learning:** ใช้เทคนิค **FORCE Learning** เพื่อให้ AI สามารถเรียนรู้และปรับปรุงโมเดลพยากรณ์ได้ทันทีในขณะที่กำลังทำงาน
* **Hardware Optimization:** แทนที่ฟังก์ชัน `tanh` ด้วยฟังก์ชันที่คำนวณง่ายกว่า (PWL/pseudo_tanh) เพื่อประหยัดพื้นที่หน่วยความจำบน FPGA

### 🧠 3. CBM-Dual: ชิปบูรณาการอเนกประสงค์
สถาปัตยกรรมระดับสูงที่รวมการประมวลผลสองรูปแบบ:
* **Simulated Annealing (SA):** สำหรับแก้ปัญหาการจัดลำดับหรือเส้นทาง (Combinatorial Optimization) ที่ซับซ้อนในระดับเรียลไทม์
* **Reservoir Computing (RC):** สำหรับการรับรู้และพยากรณ์สภาพแวดล้อมที่เปลี่ยนแปลงตลอดเวลา
* **Unified Processor:** ประกอบด้วย 1024 นิวรอนแบบ Chaotic Boltzmann Machine (CBM) ที่สลับโหมดการทำงานได้อิสระ
